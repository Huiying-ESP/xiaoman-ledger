# 小满记账

绿色小猫风格的无广告个人记账本，支持支出与收入、月度预算、历史补录、月度及年度分析、加密备份与离线使用。

## GitHub Pages 发布

将本目录内容放在仓库根目录。在 Settings → Pages 中选择 Deploy from a branch，选择 main 分支与 / (root)，保存。

账目保存在各设备浏览器的 IndexedDB 中，不上传至 GitHub。不同网址的本地账目不会自动迁移，请先在原网址导出加密备份，再在新网址恢复。

建议先在 Safari 打开，等待“我的”页显示离线资源已准备好，再添加到主屏幕。首次加载及应用更新仍需要能访问托管地址。

更新应用时请同步修改 sw.js 的缓存版本。
